# PeerCode — Free DSA Mock Interviews

A free peer-to-peer DSA mock interview platform.
Book a slot, get matched with a peer, practice DSA
problems, and swap interviewer/interviewee roles.

## Live

https://peercode.live

## Features

- Scheduled slot booking
- Peer matching system
- Role swap (interviewer/interviewee)
- 100+ DSA questions with hidden test cases
- Code editor with run & submit
- Video/audio via WebRTC
- Session history & ratings
- Email notifications

## Tech Stack

Frontend: React, TypeScript, Tailwind, Vite  
Backend: Node.js, Express, Socket.io  
Database: Supabase (PostgreSQL)  
Auth: Supabase Auth + Google OAuth  
Emails: Resend  
Hosting: Vercel + Render
